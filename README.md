# Javelimeeter

Mixer audio virtuel pour Windows : pistes, sorties A/B, VST, push-to-talk, plugin Stream Deck.

## Télécharger
➡️ **[Dernière version](../../releases/latest)** — prends le fichier `Javelimeeter-Setup-….exe`.

## Installer
1. Lance l'installateur. Les câbles audio virtuels VB-Audio sont proposés s'ils ne sont pas déjà installés
   (un redémarrage de Windows peut être demandé).
2. Au premier lancement, Javelimeeter affiche le **code de ton PC** : envoie-le à la personne qui t'a donné Javelimeeter.
3. Colle la **clé de licence** reçue, puis « Activer ».

Javelimeeter est un logiciel privé : **une licence est nécessaire** pour l'utiliser.

## Stream Deck (facultatif)
Dans la même page de version : `com.javelimeeter.mixer.streamDeckPlugin` (double-clic pour l'installer)
et le profil `Javelimeeter XL.streamDeckProfile`.

## Mettre à jour
Télécharge la nouvelle version et lance-la par-dessus : réglages et licence sont conservés.
